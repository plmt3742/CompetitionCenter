# 内部工作台 · 高保真设计

参考本地「助理台」的黑白极简、圆润卡片、顶部胶囊导航与时间余额布局，落到竞赛中心的内部工作台。

## 打开

直接双击 `index.html`，或在浏览器打开：

```text
docs/20-requirements/blueprint/hifi-workspace/index.html
```

无需构建、无外部依赖；`style.css` 与 `app.js` 与本页同目录。

## 覆盖内容

- 顶部：品牌、胶囊导航、全局搜索、快速收集、日期、明暗主题。
- 首屏：问候、今日概览、日期印章。
- 时间余额：今天 / 本周 / 本月 / 本学期剩余时间，最近节点倒计时。
- 四张指标卡：待办、本周完成、收集待处理、接洽待跟进。
- 七张工作卡：今日聚焦、赛事进展、收集箱、缺件风险、近 14 天入档、最近活动、档案速览。
- 页脚：数据源、最后同步、版本。

## 交互

- 明暗主题切换，记住选择。
- 待办分类筛选（全部 / 赛事 / 收集 / 交接）。
- 待办勾选完成，指标数字同步变化。
- 时间余额、时钟、倒计时实时更新。
- 近 14 天入档折线图随卡片进入播放。
- 快速收集/搜索按钮给出原型提示。

## 数据

全部为示例数据，不含真实姓名、学号、手机号、成绩与赛题。接入真实数据前，按 `data/README.md` 的 L1–L4 分级处理。
