## 2. 应用外壳

### 公开端外壳

- 顶部：中心名称、赛事、通知、成果、关于、联系。
- 页脚：联系方式、隐私说明、更新时间。
- 不做登录态导航；报名页可按需轻量登录。
- 所有页面可缓存、可分享；移动端优先保证赛事详情与报名。

### 内部端外壳

- 左侧导航：工作台、卷宗、收集箱、接洽、组织、交接、设置。
- 顶部：全局搜索、快速收集、通知、用户菜单。
- 面包屑：卷宗 → 阶段 → 条目。
- 导航按权限显示；无权限的入口不出现，但直接访问 URL 会得到明确拒绝页。

## 3. 公共页面规则

- 每页只有一个主操作；次要操作放更多菜单。
- 标题、面包屑、返回路径必须清楚；从搜索进入时保留筛选条件。
- 六种状态必须设计：加载、空、错误、无权限、已归档、并发冲突。
- 空状态给下一步动作，例如“还没有赛事，先创建卷宗”。
- 危险操作二次确认并填写原因：归档、删除、下架、权限转移。

## 4. 重点页面展开

### P-03 赛事详情

| 区块 | 内容 | 显示规则 |
|---|---|---|
| 头部 | 名称、届次、状态、时间、类型 | 只有已发布 L1 |
| 时间线 | 报名、赛前、比赛、评审、公示 | 未开始显示计划日期，不显示内部备注 |
| 规则与资料 | 规则、FAQ、模板下载 | 只显示 L1 且已发布 |
| 报名 | 入口、截止、资格、联系人 | 截止后显示关闭状态与咨询入口 |
| 结果 | 获奖名单、报道 | 公示发布后才出现 |
| 相关通知 | 该赛事通知 | 最多 5 条，更多进列表 |

设计逻辑：对外信息只来自已发布条目；缺失区块直接隐藏，不留空壳；报名与结果不复制内容，引用条目。

### I-02 工作台

| 卡片 | 内容 | 排序 |
|---|---|---|
| 我的任务 | 指派给我、未完成、临近截止 | 截止日升序 |
| 待处理收集 | 我提交/我负责、未入档 | 最老优先 |
| 临近节点 | 我参与的卷宗阶段截止 | 7 天内高亮 |
| 风险提醒 | 缺件、超期、权限即将到期 | 严重度降序 |
| 最近活动 | 我参与的卷宗变更 | 时间倒序 |

设计逻辑：工作台是“行动入口”，不是数据大屏；每张卡片都能跳到已筛选列表；没有数据时显示下一步，不显示零值图表。

### I-04 卷宗详情

| 区域 | 内容 | 主操作 |
|---|---|---|
| 头部 | 标题、类型、届次、状态、负责人、密级 | 编辑 / 推进阶段 |
| 阶段时间线 | 七阶段状态、负责人、时间窗 | 进入某阶段 |
| 完整性 | 必备项、缺件、责任人 | 创建缺件 / 指派 |
| 标签页 | 条目、任务、成员、交接、活动 | 切换视图 |
| 条目列表 | 按阶段/类型/密级筛选 | 新建 / 打开 |
| 任务 | 本卷宗任务 | 指派 / 完成 |
| 成员 | 本卷宗角色 | 添加 / 移除 |
| 交接 | 赛事包生成与历史 | 生成 / 签字 |

设计逻辑：所有工作围绕卷宗；切换标签不丢筛选；归档后整页只读，保留导出。

### I-06 收集箱

| 区域 | 内容 | 主操作 |
|---|---|---|
| 快速登记 | 标题、来源、密级 | 保存 |
| 队列 | 待分诊、处理中、待复核、已入档 | 切换视图 |
| 分诊抽屉 | 关联卷宗/阶段/类型、处理人 | 保存分诊 |
| 复核 | 原稿与草稿条目并排 | 通过 / 退回 |
| 批量 | 指派、改密级、归档 | 批量执行 |

设计逻辑：收集与入档分离；收集可以粗糙，入档必须干净；任何动作可追溯，拒绝要写原因。

## 5. 页面验收

- 每个页面能说清：服务谁、主操作是什么、无权限时看到什么。
- 公开端不出现任何 L2–L4 字段；内部端不出现未授权数据。
- 空、错、载入、无权限、归档、冲突六态都有设计。
- 移动端能完成：收集、看任务、看赛事详情。
- 所有 URL 稳定；slug 发布后不改。
