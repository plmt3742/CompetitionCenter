# 功能清单

## 优先级

| 标记 | 含义 |
|---|---|
| M | 该阶段必须有，没有就不能验收 |
| S | 应该有，时间允许就做 |
| C | 可以做，后续再看 |
| W | 当前明确不做 |

阶段对应 `01-roadmap.md` 的 P1–P4。

## MVP 切割线（P1）

必须做：ARC-01、ARC-02、ARC-03、ARC-04、ARC-05、ARC-06、ARC-07；INT-01、INT-02、INT-03；ORG-01、ORG-02、ORG-04；PLT-01、PLT-02、PLT-03、PLT-07、PLT-09。

暂不做：对外门户、报名、交接包、任务看板、自动提醒、批量导入。

## 功能依赖

- 权限（PLT-02）必须先于档案（ARC）与收集（INT）。
- 卷宗模板（ARC-01）决定完整性清单（ARC-05），两者要一起设计。
- 交接包（ARC-11/HND-02）依赖档案元数据与任务状态，不能提前做。
- 对外发布（EXT-07）依赖密级（ARC-07）与审校流程。

## 明确不做

- 通用 IM、论坛、视频平台。
- 在线评测与判题。
- 财务/报销、人事/考勤、绩效。
- 通用 CMS 与页面搭建器。
- 自动 AI 归档。
