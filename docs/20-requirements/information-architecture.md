# 信息架构

## 两个界面

| 界面 | 访问 | 内容 | 数据来源 |
|---|---|---|---|
| 公开端 portal | 无需登录 | 赛事、通知、成果、关于、报名、咨询 | 已发布的 L1 条目 |
| 内部端 workspace | 登录 | 工作台、卷宗、收集箱、组织、交接、设置 | 全部授权数据 |

两边共用同一套内容，不维护两份。对外发布是条目的一次状态变更，不是复制粘贴。

## 公开端

| 路径 | 页面 | 内容 | 登录 |
|---|---|---|---|
| `/` | 首页 | 中心简介、近期赛事、最新通知、成果入口 | 否 |
| `/competitions` | 赛事列表 | 按年份/类型筛选，进行中优先 | 否 |
| `/competitions/:slug` | 赛事详情 | 简介、时间线、规则、报名、结果、资料下载 | 否 |
| `/notices` | 通知列表 | 按年份/赛事筛选 | 否 |
| `/notices/:id` | 通知详情 | 正文、附件、相关赛事 | 否 |
| `/results` | 成果 | 获奖名单、活动报道 | 否 |
| `/about` | 关于 | 中心定位、组织、历史 | 否 |
| `/contact` | 咨询/合作 | 表单、FAQ、联系人 | 否 |
| `/register/:event` | 报名 | 外链表单或内建表单 | 视方案 |

公开端规则：

- 只显示 `classification = L1 AND published = true` 的条目。
- 不显示内部批注、评分、评审意见、原始报名表。
- 任何页面不出现选手手机号、学号、邮箱。
- 赛事结束后详情页保留，结果与复盘按需更新。

## 内部端

| 路径 | 页面 | 内容 | 主要角色 |
|---|---|---|---|
| `/workspace` | 工作台 | 我的任务、待处理收集、临近节点、风险 | 全员 |
| `/cases` | 卷宗库 | 赛事与运营卷宗，按年份/类型/状态筛选 | 全员 |
| `/cases/:id` | 卷宗详情 | 阶段、完整性、条目、任务、成员、交接包 | 赛事负责人 |
| `/intake` | 收集箱 | 待处理、处理中、待复核、已入档 | 全员 |
| `/outreach` | 接洽台账 | 合作方、评委、赞助商联系人、沟通记录、状态 | 外联 + 中心负责人 |
| `/org` | 组织 | 成员、组、岗位、任职、负载 | 组负责人+ |
| `/handover` | 交接 | 岗位包、赛事包、核对记录 | 组负责人+ |
| `/settings` | 设置 | 模板、权限、审计、保留策略 | 中心负责人 |

说明：

- "赛事管理"不单独做一级菜单，用 `/cases?type=competition` 过滤，避免卷宗与赛事两套数据。
- 卷宗详情是主工作台：所有档案、任务、清单都从这里进入。
- 收集箱是全局入口，不要求先选赛事；归类可以后补。

## 内容类型与归属

| 内容 | 公开端 | 内部端 | 默认密级 |
|---|---|---|---|
| 赛事介绍 | 详情页 | 卷宗摘要 | L1 |
| 通知公告 | 通知列表 | 条目 | L1/L2 |
| 规则/FAQ | 详情页 | 条目 | L1 |
| 报名表 | 报名页（表单） | 收集/报名条目 | L3 |
| 选手名单 | 脱敏后可选 | 条目 | L3 |
| 赛题/数据 | 赛后按规则 | 条目 | L4 |
| 成绩/排名 | 公示后 | 条目 | L3→L1 |
| 评审意见 | 不展示 | 条目 | L4 |
| 媒体素材 | 成果/报道 | 条目 | L1/L2 |
| 复盘 | 可选摘要 | 条目 | L2 |
| 岗位包/交接包 | 不展示 | 交接页 | L2 |

## 导航

公开端：赛事 · 通知 · 成果 · 关于 · 联系（报名从赛事详情进入）。

内部端：工作台 · 卷宗 · 收集箱 · 接洽 · 组织 · 交接 · 设置。

移动端优先保证：收集箱登记、工作台待办、赛事详情查看。

## 搜索

- 内部端全局搜索：卷宗、条目、收集项、任务、成员；结果按密级过滤。
- 公开端只搜已发布 L1；先做列表筛选，全文搜索可后置。
- 搜索维度见 [`../10-concepts/archive-model.md`](../10-concepts/archive-model.md)。

## 发布流程

```text
条目 draft → 负责人复核（内容/密级）→ 审校（对外口径）
          → published（公开端可见）→ 下架/归档
```

规则：

- 发布动作记录操作人、时间、审校人。
- 下架不删除，保留内部副本。
- 同一赛事对外信息只在一个主渠道发布，其他渠道引用链接。

## URL 约定

- 赛事：`/competitions/2026-algo-elite`
- 通知：`/notices/2026-11-21-registration-open`
- 内部卷宗：`/cases/<id>`
- 不使用中文拼音全拼以外的不稳定标识；slug 一旦发布不改。
