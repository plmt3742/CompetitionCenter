# 文档索引

设计阶段的文档都在这里。建议按下面的顺序读。

## 阅读顺序

1. `00-charter.md` — 为什么做、做到什么算成功
2. `01-roadmap.md` — 先做什么、后做什么
3. `10-concepts/` — 四个核心模型
4. `20-requirements/` — 要哪些功能、页面怎么组织、板块怎么设计
5. `30-architecture/` — 模块边界与数据流
6. `50-operations/handover.md` — 系统最终要解决的交接问题
7. `20-requirements/blueprint/wireframes.html` — 低保真线框（浏览器打开）

## 写作约定

- 结论先行，先给判断再给论证。
- 事实与假设分开；拿不准的写进「未决问题」，不写成结论。
- 文档用中文；字段名、标识符、命令用英文。
- 单篇控制在 400 行以内，超了先拆分。
- 不写真实人名、学号、手机号、未公示成绩与赛题。
