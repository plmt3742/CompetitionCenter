# 竞赛中心 · CompetitionCenter

计算机科学与技术学院竞赛中心的信息管理与对外协同平台。

> 当前状态：**设计已清空，等待重新设计**。仓库只保留骨架与数据规则。

## 数据红线

- 真实选手姓名、学号、手机号、成绩、评审细节**不进入本仓库**。
- 原始资料只放本地 `data/raw/`（已被 gitignore），入库前脱敏。
- 对外只发布 L1 内容；L3/L4 按赛事授权访问。
- 详见 [`data/README.md`](data/README.md)。
